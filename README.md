# ControlSight

ControlSight is a web-based project controls and performance intelligence platform.

The project demonstrates how project cost, schedule, procurement, progress and data-quality reporting can be delivered through a custom web application using Python, SQL, FastAPI, HTML, CSS and JavaScript.

## Architecture

Raw business data

→ Python ETL

→ SQL database

→ FastAPI backend

→ HTML/CSS/JavaScript frontend

→ Interactive management dashboard

## Main Areas

- Executive Overview
- Cost Analytics
- Schedule Performance
- Procurement Monitoring
- Data Quality
- Management Insights
