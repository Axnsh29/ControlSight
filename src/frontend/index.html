Validation & Data Quality

Transparent view of records entering the validation layer, accepted records, quarantined records and logged issue events.

Source Records — Presented to validation
Accepted Records — Loaded to analytical layer
Quarantined Records — Excluded after validation
Issue Events — Logged validation observations
Validation Pass Rate — Accepted ÷ Source
Validation semantics

Quarantined records are invalid source records excluded from the controlled analytical layer. Issue events are validation observations and may include multiple observations for the same record, so issue-event count does not need to equal quarantined-row count.
